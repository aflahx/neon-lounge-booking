# Blackout Gaming Cafe — Premium Neon Gaming Website

Build a **premium, immersive, mobile-first website for Blackout Gaming Cafe, Kochi, Kerala**.

This should NOT look like a generic gaming template. The website should feel like walking into a dark, high-end gaming lounge: **black environment, neon purple lighting, subtle glow, gaming atmosphere, cinematic animations, glassmorphism, strong typography, and smooth interactions**.

The website must still be easy for normal customers to understand. Most visitors will be students and young adults discovering the cafe through Instagram/WhatsApp, so the important information—**games, pricing, location, opening hours and booking**—must be immediately accessible.

---

## 1. Brand Identity

Business name:

**BLACKOUT GAMING CAFE**

Main tagline:

**PLAY • FOCUS • DOMINATE**

Brand personality:

* Premium
* Dark
* Energetic
* Gaming-focused
* Modern
* Slightly aggressive
* Social
* Youth-oriented
* Trustworthy

Primary visual direction:

* Near-black background
* Neon purple as the main accent
* White/light-gray typography
* Very subtle secondary neon accents
* Soft purple glows
* Neon borders
* Glassmorphism panels
* Dark gradients
* Atmospheric lighting
* Gaming-room ambience

Avoid making everything glow excessively. Neon should be used strategically so the website still looks premium rather than cheap.
